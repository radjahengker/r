## 🚀 Cara Menggunakan

### Opsi 1: Buka Langsung
Buka file `index.html` di browser:
```bash
start index.html
```

### Opsi 2: GitHub Pages (Hosting Gratis)
1. Buat repository baru di GitHub
2. Upload semua file:
```bash
git init
git add .
git commit -m "Initial commit - Dapur Mulia E-Commerce"
git branch -M main
git remote add origin https://github.com/username/dapur-mulia-ecommerce.git
git push -u origin main
```
3. Settings → Pages → Branch: `main`, folder: `/ (root)` → Save
4. Akses di: `https://username.github.io/dapur-mulia-ecommerce/`

### Opsi 3: Hosting Berbayar
Upload semua file ke hosting (Hostinger, Niagahoster, cPanel, dll) via File Manager / FTP.
